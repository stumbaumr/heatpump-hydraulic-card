- Flow dashes, fans and pumps no longer jump when their speed changes. A new flow rate, modulation or fan speed set a new animation duration, which moved the running animation to another point of its cycle: with a flow rate that changes every few seconds (HeishaMon), the dashes seemed to flow backwards for a moment. The animations now run for 1 s in the stylesheet, and the card sets their speed with `updatePlaybackRate()`, which keeps the current position.
